# OneChat

โคลนจาก OneChat Mockup (artifact ที่ทีมส่งมา) ครบทุกหน้า ทุกข้อความ ทุกข้อมูลตัวอย่าง และทุกการกระทำ
หน้าตาเป็นไปตาม **Design System ของ SmartLiff BO** (`smartliff-game-scratchhub-ds-docs/designs/design-system/DESIGN-SYSTEM.md`)
บนธีม **SmartLiff shadcn theme kit** + **ชุดสี WeChat (WeUI)** ทั้งโหมดสว่างและโหมดมืด

- **Stack:** SvelteKit 2 · Svelte 5 · Tailwind CSS v4 · shadcn-svelte (style vega · zinc) · bits-ui · ไอคอน lucide
- **ฟอนต์:** LINE Seed Sans TH ตัวเดียว รวมถึงตัวเลข (`tabular-nums`) เสิร์ฟจาก `static/fonts/` (DS §3)
- **ต้นฉบับ:** `reference/original.html` (ซอร์สเต็มของ artifact เปิดในเบราว์เซอร์ได้เลย)

## วิธีรัน

```bash
bun install
```

```bash
bun run dev
```

เปิด http://localhost:5180 · build เป็นไฟล์ static ด้วย `bun run build` (ได้โฟลเดอร์ `build/`)

## Organization → Agent → LINE Channel (เอกสารส่งต่องาน 9 ต.ค. 2026 ฉบับแก้ · ทำครบ P1 + P2)

แทนการจัดกลุ่มตามเว็บของรอบก่อน · **Agent = เว็บ** และรายการใต้ Agent (เช่น "55GOAL V1 (VIP)") คือ LINE Channel (เจ้าของงานยืนยัน) ⇒ ไม่มีข้อมูลเว็บแยกจาก Agent ไม่แสดง "เว็บ A/B/C" ใต้ Channel แล้ว

- **แถบ Merchant** (`Sidebar.svelte`): Org ปัจจุบันเป็นบริบทบนสุด (ต้นฉบับไม่มีตัวเลือก Org ⇒ แสดงอย่างเดียว) · หัวกลุ่ม Agent = checkbox ทั้ง Agent + ชื่อ + ลูกศรพับ/ขยาย + **ปุ่มตั้งค่า** (ย้ายจากทุก Channel มาไว้ระดับ Agent · 12 ต.ค. 2026)
- **แยก Agent ให้เห็นชัด**: แต่ละ Agent คั่นด้วยเส้นบน · Channel ของ Agent อยู่ใต้เส้นนำสายตาแนวตั้งที่ลากลงจาก checkbox ของ Agent · ชื่อ Channel ตัวเล็กลง 1 ขั้น (14 → 12px)
- **เลือกทั้งหมด = checkbox รวมแถว "Merchant"** (แทนปุ่ม เลือกทั้งหมด / ล้างทั้งหมด ที่เจ้าของงานเห็นว่าแปลก) · ครบ ✓ · บางส่วน − · ไม่เลือก ว่าง พร้อมตัวนับ `n/ทั้งหมด` (ไม่เลือกเลยแสดงว่า "แสดงทั้งหมด")
- **ฟังก์ชันอ่านแยกต่อ Channel** (`chat` · `liff`): แถบนี้แสดงเฉพาะ Channel ที่เปิดแชทรวม · ไม่มีป้าย = แชทรวมอย่างเดียว · ป้าย "+ LIFF" = เปิดทั้งสองอย่าง · **LINE LIFF เท่านั้นไม่แสดงในแถบนี้** (เจ้าของงานสั่ง · ยังอยู่ในข้อมูล) · Agent ที่ไม่เหลือ Channel ก็ไม่แสดง
- **checkbox เป็นตัวกรองรายการสนทนาเท่านั้น** ไม่แตะค่าฟังก์ชันหรือ Permissions · เลือกทั้ง Agent / เลือกทั้งหมด เลือกเฉพาะช่องที่เลือกแชตได้
- ทุก Channel มี Agent เสมอ (เจ้าของงานยืนยัน ⇒ ไม่มีกลุ่ม "ไม่พบข้อมูล Agent")
- **หัวแชต**: แถวเดียว — รูปลูกค้า · ชื่อ · ป้ายประเภท · LINE Channel (@id) (เจ้าของงานให้เอาบรรทัด Org / Agent ออก 12 ต.ค. 2026) · **รายการสนทนา / ผลค้นหา**: ชื่อ Channel เหมือนเดิม
- **ไม่ติ๊ก Channel เลย = ไม่แสดงแชต** (เจ้าของงานเปลี่ยน 12 ต.ค. 2026 — ตรงกับเอกสารส่งต่องาน) · รายการขึ้น "ยังไม่ได้เลือก Channel" · ห้องแชทและแผงลูกค้าว่าง · เปิดระบบมาติ๊กไว้ทุก Channel ที่เลือกแชตได้ · เปิดจากผลค้นหา ⇒ ติ๊ก Channel ของลูกค้าคนนั้นให้

ข้อมูลสมมติใน `data.js` (`org` · `agents` · `CHANNEL_META`) — กำหนดตรงต่อ Channel ไม่เดาจากชื่อ · เพิ่ม 2 ช่องทดสอบที่ไม่มีในต้นฉบับ (`MEMBER LIFF` · `PROMO LIFF`):

```text
Organization ตัวอย่าง
├── Agent A   55GOAL V1 (VIP) │ 99QUEEN.COM · แชต+LIFF │ LONDON789 │ 99KING.COM
├── Agent B   55GOAL WN │ 99QV1 (VIP) · แชต+LIFF │ 99CENTER ใหม่ │ DNA │ MEMBER LIFF · LIFF เท่านั้น
└── Agent C   PROMO LIFF · LIFF เท่านั้น   (ไม่แสดงในแถบ เพราะไม่มี Channel สำหรับแชต)
```

| เกณฑ์ตรวจรับ | ผล |
|---|---|
| เห็น Org เป็นบริบท · Agent เป็นหัวกลุ่ม · Channel อยู่ใต้ Agent ที่ถูกต้อง | ✓ |
| แต่ละสนทนาแสดง Channel · หัวแชตแสดง Channel ตรงกับรายการที่เปิด (บรรทัด Agent เอาออกตามที่สั่ง) | ✓ |
| พับ/ขยายกลุ่ม การเลือกและการกรองคงเดิม | ✓ |
| เลือก/ยกเลิกทั้ง Agent มีผลเฉพาะช่องที่เลือกแชตได้ของ Agent นั้น | ✓ (Agent B เลือก 3 ไม่รวม MEMBER LIFF) |
| เลือกบาง Channel ⇒ หัวกลุ่มสถานะบางส่วน | ✓ |
| เลือกทั้งหมด/ล้างทั้งหมด (checkbox รวม) | ✓ |
| Agent เดียวกันเปิดฟังก์ชันต่างกัน · ช่องเปิดทั้งแชตและ LIFF เลือกแชตได้ | ✓ |
| Agent ไม่มี Channel สำหรับแชต | ✓ ไม่แสดงทั้งกลุ่ม (Agent C) |
| ข้อมูลเจ้าของหาย | — ไม่มีกรณีนี้ (เจ้าของงานยืนยัน) |
| ชื่อยาว ไม่ทับปุ่ม | ✓ |
| ตรวจสิทธิ์ | — ต้นแบบไม่มีระบบสิทธิ์ (`canChat` ใน `data.js` คือจุดที่ต้องเพิ่มสิทธิ์จริง) |
| Setting · รับเคส · ตอบ · ปิดเคส · ตั้งค่า Channel | ✓ ทำงานเดิม |

**ยังรอข้อมูลจากทีม**: รหัส Org · Agent · Channel จริง · ค่าฟังก์ชันแชทรวม/LIFF จริงต่อ Channel · กติกาสิทธิ์เดิม (รวมที่สืบทอดจาก Org/Agent)

## ปุ่มสติ๊กเกอร์ในหน้าแชต (เพิ่ม 12 ต.ค. 2026 · ต้นฉบับมีหน้าตั้งค่าแต่ไม่มีที่ใช้)

- ปุ่มไอคอนสติ๊กเกอร์ในช่องพิมพ์ (`StickerPicker.svelte` · `popover` ของ shadcn) เปิดแผงเลือก: **สติ๊กเกอร์โปรด** ก่อน แล้วตาม **ชุดที่บันทึกไว้** (ชุดที่กดดาวขึ้นก่อน) — ทั้งหมดมาจาก Settings › ชุดสติ๊กเกอร์
- กดสติ๊กเกอร์ = ส่งทันทีแล้วปิดแผง · รับเคสให้อัตโนมัติถ้ายังรอแอดมิน (เหมือนส่งข้อความ) · ปิดเคสแล้วปุ่มกดไม่ได้
- ในห้องแชตแสดงเป็นกล่องสติ๊กเกอร์ (ต้นแบบไม่มีรูปจริง ⇒ ไอคอน + "ชุด 446 #1") · รายการแชตแสดง "[สติ๊กเกอร์]"
- ยังไม่มีชุดและไม่มีสติ๊กเกอร์โปรด ⇒ แผงบอกให้ไปตั้งค่า + ปุ่ม [ไปที่ชุดสติ๊กเกอร์]
- ⚑ ต้นฉบับเก็บชุดเป็นแค่ชื่อกับจำนวน ⇒ เพิ่ม `items` (รหัสสติ๊กเกอร์ในชุด) ใน `store.svelte.js` ให้ส่งได้จริง · แก้ชุดเดิมแล้วได้สติ๊กเกอร์ชุดเดิมกลับมา (ต้นฉบับใส่ "id-1…" แทน)

## ผังหน้าแชตและความแน่น (ปรับ 12 ต.ค. 2026)

- **ผังแบบช่องคั่นเส้น** (เจ้าของงานให้ทำเหมือนเมนู Organization): เมนูข้าง │ รายการแชท │ ห้องแชท │ แผงลูกค้า
  ทุกช่องเต็มสูง ชนกันด้วยเส้น 1px ไม่มีการ์ดลอยหรือช่องว่างรอบ ๆ
  - รายการแชท: พื้น `bg-surface-chrome` เท่าเมนูข้าง + เส้นขวา
  - แผงลูกค้า: พื้น `bg-surface-chrome` + เส้นซ้ายคั่นจากห้องแชท · บล็อกข้างในเป็นการ์ด (sm) ห่างกัน 12px
  - ห้องแชท: **ทั้งก้อนเป็นการ์ดลอย** (มุมมน ขอบบาง เงา sm · ห่างจากขอบ 12px / มือถือ 8px) บนพื้นหน้า — เจ้าของงานสั่ง · พื้นข้อความเทา `--muted` (มืด `--background`) ฟองลูกค้าขาวมีขอบ ฟองแอดมินสีแบรนด์ — สีเดิม · หัวห้องมีรูปโปรไฟล์ลูกค้า
  - จอต่ำกว่า xl: แถบสลับมุมมองอยู่บนพื้นเมนู + เส้นล่าง
- **ห้องแชทกว้างขึ้น**: `--grid-console-xl` 19rem·1fr·21rem ⇒ 18rem·1fr·20rem · `--grid-console-md` 18rem ⇒ 17rem
- **ระยะแน่นขึ้น** (ทุกค่ายังเป็นขั้นของ 4px):

  | ตำแหน่ง | เดิม | ใหม่ |
  |---|---|---|
  | ขอบหน้าแชต / ช่องระหว่างคอลัมน์ | 16 / 16px | 0 (คั่นด้วยเส้น) |
  | ระยะในช่องของหน้าแชต (`#consoleWrap` → `--card-spacing`) | 20px · 16px (sm) | 12px |
  | หัวรายการ/ห้องแชท | py 16 · gap 12 | py 12 · gap 8 |
  | แถวรายการแชท | py 12 | py 8 |
  | พื้นข้อความ | p 16 · gap 12 | p 12 · gap 10 |
  | แถว Channel ในเมนูข้าง | 40px | 36px |
- หน้าตั้งค่าและหน้าข้อความอัตโนมัติยังใช้การ์ดและระยะมาตรฐานของ DS (20px)
- ห้องแชทแคบกว่า 28rem (container query) ปุ่ม "จำลองสลิป" เหลือแค่ไอคอน (มี aria-label) ให้ช่องพิมพ์กว้างขึ้น
- ช่องพิมพ์: ปุ่มสติ๊กเกอร์อยู่ซ้ายสุด · ปุ่มคีย์ลัดเป็นตัวหนังสืออย่างเดียว ไม่มีไอคอน (เจ้าของงานสั่ง ยกเว้นกฎ DS ข้อปุ่มต้องมีไอคอน)
- ปุ่ม "ปิด [F4]" เป็นสีแดงทึบ (`data-tone="destructive" data-fill="solid"`) ตามที่เจ้าของงานสั่ง

## แผงลูกค้า (ปรับ 12 ต.ค. 2026 ตามที่เจ้าของงานชี้ทีละจุด)

- **ตรวจสอบสถานะไลน์**: เลิกใช้ตาราง 4 คอลัมน์ที่ต้องเลื่อนซ้าย–ขวา ⇒ กล่องเดียว `#ลำดับ · ชื่อ @id · ป้ายสถานะ` · ไลน์หลุด ⇒ กรอบแดงอ่อน + ข้อความ + ปุ่ม Verify ในกล่อง

## หน้าตั้งค่า (ปรับ 12 ต.ค. 2026)


- **ระยะรอบหน้าแน่นขึ้น**: ขอบซ้าย/ขวา 12px (จาก 28px) · ช่องระหว่างเมนูกับเนื้อหา 12px
- **คู่มือการใช้งาน** (`GUIDE` ใน `data.js`) เขียนใหม่ให้ตรงกับหน้าจอปัจจุบัน 13 หัวข้อ เรียงตามลำดับงาน: เลือก Channel → รายการสนทนา (สีเคส) → ตอบแชท → ตรวจสลิป → แผงลูกค้า → ตั้งค่า (แผงสไลด์) → สติ๊กเกอร์ → คีย์ลัด → Broadcast → ข้อความอัตโนมัติ → บัญชี → Telegram → ปุ่มคีย์ลัด (Announce)
- **สร้าง/แก้ไขทุกหน้าเปิดเป็นแผงสไลด์จากด้านขวา** (`formSheet` ใน `SettingsPage.svelte`): ปุ่มสร้างใหม่อยู่แถวเดียวกับหัวการ์ดรายการ — ชุดสติ๊กเกอร์ · คีย์ลัด · กฎข้อความอัตโนมัติ · บัญชี · โพสต์ Telegram · หัวแผงบอก "สร้าง…ใหม่" หรือ "แก้ไข…: ชื่อ" · แถวที่กำลังแก้มีป้าย "กำลังแก้ไข" · บันทึกสำเร็จ ⇒ ปิดแผง + toast · ปิดแผง = ยกเลิก (`S.sheet` ใน `store.svelte.js`)
- **รูปสติ๊กเกอร์จริง** จาก CDN ของ LINE (`stickerSrc()` ใน `data.js` · ชุดพื้นฐาน 446/789/1070/6136/6325/6359 ของ Messaging API · `ui/StickerImg.svelte` โหลดไม่ได้ ⇒ ไอคอนแทน) ใช้ในสติ๊กเกอร์โปรด · คลัง · สติ๊กเกอร์ในชุด · ปุ่มสติ๊กเกอร์หน้าแชท · ข้อความสติ๊กเกอร์ในห้องแชท (รูปลอยไม่มีฟองแบบ LINE)
- **รายการสติ๊กเกอร์ในคีย์ลัด / Broadcast เลือกจากรูป** (`ui/StickerField.svelte`): ไม่ต้องจำชื่อชุดหรือ Sticker ID — กดแล้วเลือกจากแท็บ โปรด · ชุดของฉัน · คลัง LINE · ปุ่มแสดงรูปที่เลือก
- **รายการรูปภาพต้องอัปโหลดเอง** (`ui/ImageField.svelte`): ต้นฉบับมีแค่ช่องพิมพ์ "ชื่อไฟล์รูป (ตัวอย่าง)" ไม่มีการอัปโหลดหรือคลังรูป · LINE ส่งรูปได้จากลิงก์ HTTPS ของไฟล์ JPG/PNG ไม่เกิน 10 MB ที่ระบบเราเก็บไว้ ⇒ แอดมินต้องอัปโหลดรูป · ต้นแบบตรวจชนิด/ขนาดไฟล์และแสดงรูปจากเครื่อง (ยังไม่ส่งขึ้นเซิร์ฟเวอร์ — ทีมหลังบ้านต้องทำที่เก็บรูปและคืนลิงก์ HTTPS)
- ตัวอย่างในแชทของคีย์ลัดแสดงรูปสติ๊กเกอร์และรูปที่อัปโหลดจริง
- **แถบ "ปิดเคส โดย …" ในห้องแชทกลับเป็นสีแดงแบบต้นฉบับ** (พื้นแดงอ่อน ตัวแดงเข้ม กึ่งกลาง ตัวหนา · โหมดมืดพื้นแดงเข้ม ตัวชมพู)
- **เลือกทั้งชุด**: คลัง LINE ในการ์ดสติ๊กเกอร์โปรดมีปุ่ม [ติดดาวทั้งชุด / เอาดาวออกทั้งชุด] · แผงสร้างชุดมี [เลือกทั้งชุด / ยกเลิกทั้งชุด]
- **ชุดสติ๊กเกอร์ แยก 2 เรื่องออกจากกัน** (การ์ดสติ๊กเกอร์โปรดขึ้นก่อน) (เดิมเลือกสติ๊กเกอร์โปรดปนกับการสร้างชุด ทำให้งง):
  1. การ์ด **ชุดสติ๊กเกอร์** — รายการชุด + ปุ่ม [สร้างชุดใหม่] · โปรด / แก้ไข / ลบ ต่อแถว
  2. การ์ด **สติ๊กเกอร์โปรด** — ป้ายสติ๊กเกอร์โปรด (กด × เอาออก) + คลัง LINE ของตัวเอง กดที่สติ๊กเกอร์ = ติด/เอาดาวออก
- **สร้าง/แก้ไขชุดเปิดในแผงด้านขวา** (`Sheet`): หัวแผงบอกชัด "สร้างชุดสติ๊กเกอร์ใหม่" หรือ "แก้ไขชุด: ชื่อชุด" · แถวที่กำลังแก้ในรายการมีกรอบสีแบรนด์ + ป้าย "กำลังแก้ไข" · สติ๊กเกอร์ที่เลือกเป็นป้ายมี × · ปุ่ม [สร้างชุด] / [บันทึกการแก้ไข] + [ยกเลิก] · ปิดแผง = ยกเลิก · บันทึกแล้วแจ้งด้วย toast
- **รายการในคีย์ลัด / Broadcast เป็นแถวเดียวแบบต้นฉบับ**: ปุ่มจับ · ลำดับ · ประเภท · ช่องกรอก · ลบ
- **จัดลำดับได้จริง**: ลากทั้งแถวด้วยปุ่มจับ ⠿ หน้าแถว (เดิมมีแต่ข้อความบอก ไม่มีที่ให้ลาก) · คีย์บอร์ด: โฟกัสปุ่มจับแล้วกดลูกศรขึ้น/ลง (action `mv-qr` / `mv-bc` ใน `store.svelte.js`)
