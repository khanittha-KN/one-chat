# OneChat

โคลนจาก OneChat Mockup (artifact ที่ทีมส่งมา) ครบทุกหน้า ทุกข้อความ ทุกข้อมูลตัวอย่าง และทุกการกระทำ
หน้าตาเป็นไปตาม **Design System ของ SmartLiff BO** (`smartliff-game-scratchhub-ds-docs/designs/design-system/DESIGN-SYSTEM.md`)
บนธีม **SmartLiff shadcn theme kit** + **ชุดสีประยุกต์จาก LINE** (`line-shadcn-theme.css` · 14 ต.ค. 2026 · ไม่ใช่ธีมทางการของ LINE · เดิมชุดสี WeChat) ทั้งโหมดสว่างและโหมดมืด

- **Stack:** SvelteKit 2 · Svelte 5 · Tailwind CSS v4 · shadcn-svelte (style vega · zinc) · bits-ui · ไอคอน lucide
- **ฟอนต์:** LINE Seed Sans TH ตัวเดียว รวมถึงตัวเลข (`tabular-nums`) เสิร์ฟจาก `static/fonts/` (DS §3)
- **ต้นฉบับ:** `reference/original.html` (ซอร์สเต็มของ artifact เปิดในเบราว์เซอร์ได้เลย)

## วิธีรัน

```bash
bun install
```

```bash
bun run dev
```

เปิด http://localhost:5180 · build เป็นไฟล์ static ด้วย `bun run build` (ได้โฟลเดอร์ `build/`)

## Organization → Agent → LINE Channel (เอกสารส่งต่องาน 9 ต.ค. 2026 ฉบับแก้ · ทำครบ P1 + P2)

แทนการจัดกลุ่มตามเว็บของรอบก่อน · **Agent = ชื่อเว็บ** และรายการใต้ Agent คือ LINE Channel ของเว็บนั้น **เว็บละกี่ช่องก็ได้** (เจ้าของงานยืนยัน 9 ต.ค. · ให้ม็อคอัพชื่อแบบ "LSM55Goal → 55Goal 1 · สำรอง · VIP · Support" 14 ต.ค. 2026) ⇒ ไม่มีข้อมูลเว็บแยกจาก Agent ไม่แสดง "เว็บ A/B/C" ใต้ Channel แล้ว

- **แถบ Merchant** (`Sidebar.svelte`): Org ปัจจุบันเป็นบริบทบนสุด (ต้นฉบับไม่มีตัวเลือก Org ⇒ แสดงอย่างเดียว) · หัวกลุ่ม Agent = checkbox ทั้ง Agent + ชื่อ + ลูกศรพับ/ขยาย + **ปุ่มตั้งค่า** (ย้ายจากทุก Channel มาไว้ระดับ Agent · 12 ต.ค. 2026)
- **แยก Agent ให้เห็นชัด**: แต่ละ Agent คั่นด้วยเส้นบน · Channel ของ Agent อยู่ใต้เส้นนำสายตาแนวตั้งที่ลากลงจาก checkbox ของ Agent · ชื่อ Channel ตัวเล็กลง 1 ขั้น (14 → 12px)
- **เลือกทั้งหมด = checkbox รวมแถว "ทั้งหมด"** (เดิมเขียน "Merchant" · เจ้าของงานให้เปลี่ยนคำ 14 ต.ค. 2026 · ข้อความในรายการว่างกับคู่มือเปลี่ยนตาม) (แทนปุ่ม เลือกทั้งหมด / ล้างทั้งหมด ที่เจ้าของงานเห็นว่าแปลก) · ครบ ✓ · บางส่วน − · ไม่เลือก ว่าง พร้อมตัวนับ `n/ทั้งหมด` (ไม่เลือกเลยแสดงว่า "แสดงทั้งหมด")
- **ฟังก์ชันอ่านแยกต่อ Channel** (`chat` · `liff`): แถบนี้แสดงเฉพาะ Channel ที่เปิดแชทรวม · ไม่มีป้าย = แชทรวมอย่างเดียว · ป้าย "+ LIFF" = เปิดทั้งสองอย่าง · **LINE LIFF เท่านั้นไม่แสดงในแถบนี้** (เจ้าของงานสั่ง · ยังอยู่ในข้อมูล) · Agent ที่ไม่เหลือ Channel ก็ไม่แสดง
- **checkbox เป็นตัวกรองรายการสนทนาเท่านั้น** ไม่แตะค่าฟังก์ชันหรือ Permissions · เลือกทั้ง Agent / เลือกทั้งหมด เลือกเฉพาะช่องที่เลือกแชตได้
- ทุก Channel มี Agent เสมอ (เจ้าของงานยืนยัน ⇒ ไม่มีกลุ่ม "ไม่พบข้อมูล Agent")
- **หัวแชต**: แถวเดียว — รูปลูกค้า · ชื่อ · ป้ายประเภท · LINE Channel (@id) (เจ้าของงานให้เอาบรรทัด Org / Agent ออก 12 ต.ค. 2026) · **รายการสนทนา / ผลค้นหา**: ชื่อ Channel เหมือนเดิม
- **ไม่ติ๊ก Channel เลย = ไม่แสดงแชต** (เจ้าของงานเปลี่ยน 12 ต.ค. 2026 — ตรงกับเอกสารส่งต่องาน) · รายการขึ้น "ยังไม่ได้เลือก Channel" · ห้องแชทและแผงลูกค้าว่าง · เปิดระบบมาติ๊กไว้ทุก Channel ที่เลือกแชตได้ · เปิดจากผลค้นหา ⇒ ติ๊ก Channel ของลูกค้าคนนั้นให้

ข้อมูลสมมติใน `data.js` (`merchants` · `org` · `agents` · `CHANNEL_META` · `lineNo`) — กำหนดตรงต่อ Channel ไม่เดาจากชื่อ · ชื่อชุดใหม่ 14 ต.ค. 2026 (เดิม Agent A/B/C กับชื่อไลน์ของต้นฉบับ เช่น 55GOAL V1 (VIP) · LONDON789 — เคสตัวอย่างย้ายตามช่องเดิมแบบหนึ่งต่อหนึ่ง) · 2 ช่องทดสอบ LIFF เท่านั้นไม่มีในต้นฉบับ:

```text
Organization ตัวอย่าง
├── LSM55Goal    55Goal 1 (@55goal1) │ 55Goal สำรอง (@55goal2) · แชต+LIFF │ 55Goal VIP (@55goalvip) │ 55Goal Support (@55goalcs)
├── LSM99Queen   99Queen 1 │ 99Queen สำรอง │ 99Queen VIP · แชต+LIFF │ 99Queen Support │ 99Queen Member · LIFF เท่านั้น
└── LSM88King    88King Promo · LIFF เท่านั้น   (ไม่แสดงในแถบ เพราะไม่มี Channel สำหรับแชต)
```

| เกณฑ์ตรวจรับ | ผล |
|---|---|
| เห็น Org เป็นบริบท · Agent เป็นหัวกลุ่ม · Channel อยู่ใต้ Agent ที่ถูกต้อง | ✓ |
| แต่ละสนทนาแสดง Channel · หัวแชตแสดง Channel ตรงกับรายการที่เปิด (บรรทัด Agent เอาออกตามที่สั่ง) | ✓ |
| พับ/ขยายกลุ่ม การเลือกและการกรองคงเดิม | ✓ |
| เลือก/ยกเลิกทั้ง Agent มีผลเฉพาะช่องที่เลือกแชตได้ของ Agent นั้น | ✓ (LSM99Queen เลือก 4 ไม่รวม 99Queen Member) |
| เลือกบาง Channel ⇒ หัวกลุ่มสถานะบางส่วน | ✓ |
| เลือกทั้งหมด/ล้างทั้งหมด (checkbox รวม) | ✓ |
| Agent เดียวกันเปิดฟังก์ชันต่างกัน · ช่องเปิดทั้งแชตและ LIFF เลือกแชตได้ | ✓ |
| Agent ไม่มี Channel สำหรับแชต | ✓ ไม่แสดงทั้งกลุ่ม (LSM88King) |
| ข้อมูลเจ้าของหาย | — ไม่มีกรณีนี้ (เจ้าของงานยืนยัน) |
| ชื่อยาว ไม่ทับปุ่ม | ✓ |
| ตรวจสิทธิ์ | — ต้นแบบไม่มีระบบสิทธิ์ (`canChat` ใน `data.js` คือจุดที่ต้องเพิ่มสิทธิ์จริง) |
| Setting · รับเคส · ตอบ · ปิดเคส · ตั้งค่า Channel | ✓ ทำงานเดิม |

**ยังรอข้อมูลจากทีม**: รหัส Org · Agent · Channel จริง · ค่าฟังก์ชันแชทรวม/LIFF จริงต่อ Channel · กติกาสิทธิ์เดิม (รวมที่สืบทอดจาก Org/Agent)

## เทียบกับ Flow ใน Figma (14 ต.ค. 2026)

Flow: [Flow-one-chat (Figma)](https://www.figma.com/design/jPdwYuMgepSCmIP0HAGPqD/Flow-one-chat?node-id=0-1) หน้า "ไลน์รวม" · ส่วนบนของไฟล์เป็นหลังบ้าน SmartLIFF Console (เปิด Organization · สร้าง/แก้ Channel · เปิด Line liff · คิดเงิน) ไม่อยู่ในต้นแบบนี้

เจ้าของงานตัดสิน 14 ต.ค. 2026:
1. **ลำดับชั้นใช้ Organization → Agent → Channel** ตามเดิม (Flow เขียน Company → Merchant แต่ให้ยึดชื่อนี้)
2. **การ์ด "จัดการเครดิต" ในแผงลูกค้ายังต้องมี** — เติม/ถอนเครดิตที่นี่ได้เลย หรือไปทำที่ Auto fast ก็ได้ (ปุ่ม "ไปหน้า Auto fast" ในผลตรวจสลิปคงไว้)
3. **เปลี่ยนรหัสผ่านมี 2 ที่**
   - **รหัสผ่านของ Agent / แอดมินที่ล็อกอินอยู่** — แท็บ **Settings › เปลี่ยนรหัสผ่าน** (รหัสปัจจุบัน · รหัสใหม่ ≥ 8 ตัว · ยืนยัน — ตรงกับ Flow) · **ทุกช่องมีปุ่มลูกตาเหมือนฟอร์มลูกค้า** (เจ้าของงานสั่ง 14 ต.ค. 2026) · เมนูมุมขวาบน "เปลี่ยนรหัสผ่าน" พาไปหน้านี้ (เดิมขึ้นแค่ toast)
   - **รหัสผ่านของลูกค้า** — ปุ่ม "เปลี่ยนรหัสผ่านลูกค้า" ในการ์ด "ตรวจสอบ" ของแผงลูกค้า · **รหัสผ่านใหม่ + ยืนยันอีกครั้ง** (≥ 6 ตัว · ไม่ตรงกัน ⇒ "ยืนยันรหัสผ่านใหม่ไม่ตรงกัน") ไม่ต้องรู้รหัสเก่า · **ทุกช่องมีปุ่มลูกตาแสดง/ซ่อนรหัส** (`ui/PasswordInput.svelte` ใช้ร่วมกับหน้า Settings · `InputGroup.Button` 24px · `aria-pressed` · แยกทีละช่อง · เปิดฟอร์มใหม่เริ่มที่ซ่อน) · บันทึกแล้วขึ้นข้อความระบบในห้องแชท (เจ้าของงานปรับ 14 ต.ค. 2026: ช่องเดียว → 2 ช่อง + ลูกตา)

ส่วนที่ Flow มีแต่ต้นแบบยังไม่มี (รอสั่งทำ): ปุ่ม "รับเคส" · Quick Reply ในแชทจากเมนูคีย์ลัด (กดด้วยเลข/คำ) · ลบ Note · รับเรื่องฝาก/ถอน · รีโหลดรูปภาพ · แนบรูป · แก้เบอร์โทร ·
สถานะถอน "ระบบกำลังโอนเงิน → ทำรายการสำเร็จ" · ช่อง "เลือกเกม" ตอนสมัครสมาชิก · แท็บ Secret Key · ค้นหาสติ๊กเกอร์

## สลิปโอนเงินเป็นรูปจริง (14 ต.ค. 2026 · เจ้าของงานส่งรูปมา)

- ห้องแชทแสดง**รูปสลิปจริง**แทนกล่องสลิปจำลอง — ไฟล์อยู่ `static/slips/` 2 รูป: กสิกรไทย → ไทยพาณิชย์ 10,000 บาท (`kbank-scb-10000.png`) · กรุงเทพ 400,000 บาท (`bbl-400000.png`)

- รายละเอียดของแต่ละรูปอยู่ที่ `SLIPS` ใน `data.js` (อ่านจากรูป) ⇒ ผลตรวจสลิปที่แผงขวา (ผู้โอน · ผู้รับ · ยอด · วันที่ · เวลา · **เลขที่รายการ** ที่เพิ่มใหม่) ตรงกับรูปเสมอ · ยอดเงินมีตัวคั่นหลักพัน
- ปุ่ม "ตรวจสอบสลิป" ใต้รูปเป็น**ปุ่มทึบสีแบรนด์** (`Button` แบบ default · เจ้าของงานสั่ง 14 ต.ค. 2026 · เดิมพื้นอ่อน `data-tone="primary"`) — ธีม LINE: พื้น #06C755 ตัวขาวทั้งสองโหมด (⚠ 2.26:1 · เจ้าของงานเลือก)
- จริง/ปลอม ยังมาจากข้อมูลของข้อความเหมือนเดิม (รูปไม่ผูกกับผล)
- **ปุ่ม "จำลองสลิป" ในช่องพิมพ์เอาออกแล้ว** (เจ้าของงานสั่ง 14 ต.ค. 2026 · ต้นฉบับมี) — สลิปในต้นแบบมาจากข้อมูลตัวอย่างใน `data.js` เท่านั้น · ช่องพิมพ์เหลือ สติ๊กเกอร์ · ข้อความ · ส่ง
- **ยอดที่ลูกค้าแจ้งในแชท · ยอดค้าง · รูปสลิป ตรงกันทุกเคสที่มีสลิป** (เจ้าของงานสั่ง 14 ต.ค. 2026) — ข้อความตัวอย่างใช้ `{amt}` แทนยอดจากรูป (`mkSlipCase` ใน `data.js`) เช่น "ฝาก 10,000 ค่ะ" · "ถอน 400,000 ครับ" · เคส D ที่ปิดแล้ว "เติมเงิน 10,000.00 บาท"

- **เมนูข้าง**: หัว Agent เรียง ชื่อ · ปุ่มตั้งค่า · ลูกศรพับ/ขยาย (ลูกศรชิดขวาสุด) · เอาป้าย "+ LIFF" ออกแล้ว (ข้อมูล `liff` ยังอยู่ใน `CHANNEL_META`)

## หน้าตั้งค่า (ปรับ 12 ต.ค. 2026)


- **ระยะรอบหน้าแน่นขึ้น**: ขอบซ้าย/ขวา 12px (จาก 28px) · ช่องระหว่างเมนูกับเนื้อหา 12px
- **คู่มือการใช้งาน** (`GUIDE` ใน `data.js`) เขียนใหม่ให้ตรงกับหน้าจอปัจจุบัน 13 หัวข้อ เรียงตามลำดับงาน: เลือก Channel → รายการสนทนา (สีเคส) → ตอบแชท → ตรวจสลิป → แผงลูกค้า → ตั้งค่า (แผงสไลด์) → สติ๊กเกอร์ → คีย์ลัด → Broadcast → ข้อความอัตโนมัติ → บัญชี → Telegram → ปุ่มคีย์ลัด (Announce)
- **สร้าง/แก้ไขทุกหน้าเปิดเป็นแผงสไลด์จากด้านขวา** (`formSheet` ใน `SettingsPage.svelte`): ปุ่มสร้างใหม่อยู่แถวเดียวกับหัวการ์ดรายการ — ชุดสติ๊กเกอร์ · คีย์ลัด · กฎข้อความอัตโนมัติ · บัญชี · โพสต์ Telegram · หัวแผงบอก "สร้าง…ใหม่" หรือ "แก้ไข…: ชื่อ" · แถวที่กำลังแก้มีป้าย "กำลังแก้ไข" · บันทึกสำเร็จ ⇒ ปิดแผง + toast · ปิดแผง = ยกเลิก (`S.sheet` ใน `store.svelte.js`)
- **รูปสติ๊กเกอร์จริง** จาก CDN ของ LINE (`stickerSrc()` ใน `data.js` · ชุดพื้นฐาน 446/789/1070/6136/6325/6359 ของ Messaging API · `ui/StickerImg.svelte` โหลดไม่ได้ ⇒ ไอคอนแทน) ใช้ในสติ๊กเกอร์โปรด · คลัง · สติ๊กเกอร์ในชุด · ปุ่มสติ๊กเกอร์หน้าแชท · ข้อความสติ๊กเกอร์ในห้องแชท (รูปลอยไม่มีฟองแบบ LINE)

- **รายการรูปภาพต้องอัปโหลดเอง** (`ui/ImageField.svelte`): ต้นฉบับมีแค่ช่องพิมพ์ "ชื่อไฟล์รูป (ตัวอย่าง)" ไม่มีการอัปโหลดหรือคลังรูป · LINE ส่งรูปได้จากลิงก์ HTTPS ของไฟล์ JPG/PNG ไม่เกิน 10 MB ที่ระบบเราเก็บไว้ ⇒ แอดมินต้องอัปโหลดรูป · ต้นแบบตรวจชนิด/ขนาดไฟล์และแสดงรูปจากเครื่อง (ยังไม่ส่งขึ้นเซิร์ฟเวอร์ — ทีมหลังบ้านต้องทำที่เก็บรูปและคืนลิงก์ HTTPS)
- ตัวอย่างในแชทของคีย์ลัดแสดงรูปสติ๊กเกอร์และรูปที่อัปโหลดจริง

- **เลือกทั้งชุด**: คลัง LINE ในการ์ดสติ๊กเกอร์โปรดมีปุ่ม [ติดดาวทั้งชุด / เอาดาวออกทั้งชุด] · แผงสร้างชุดมี [เลือกทั้งชุด / ยกเลิกทั้งชุด]
- **ชุดสติ๊กเกอร์ แยก 2 เรื่องออกจากกัน** (การ์ดสติ๊กเกอร์โปรดขึ้นก่อน) (เดิมเลือกสติ๊กเกอร์โปรดปนกับการสร้างชุด ทำให้งง):
  1. การ์ด **ชุดสติ๊กเกอร์** — รายการชุด + ปุ่ม [สร้างชุดใหม่] · โปรด / แก้ไข / ลบ ต่อแถว
  2. การ์ด **สติ๊กเกอร์โปรด** — ป้ายสติ๊กเกอร์โปรด (กด × เอาออก) + คลัง LINE ของตัวเอง กดที่สติ๊กเกอร์ = ติด/เอาดาวออก
- **สร้าง/แก้ไขชุดเปิดในแผงด้านขวา** (`Sheet`): หัวแผงบอกชัด "สร้างชุดสติ๊กเกอร์ใหม่" หรือ "แก้ไขชุด: ชื่อชุด" · แถวที่กำลังแก้ในรายการมีกรอบสีแบรนด์ + ป้าย "กำลังแก้ไข" · สติ๊กเกอร์ที่เลือกเป็นป้ายมี × · ปุ่ม [สร้างชุด] / [บันทึกการแก้ไข] + [ยกเลิก] · ปิดแผง = ยกเลิก · บันทึกแล้วแจ้งด้วย toast
- **รายการในคีย์ลัด / Broadcast เป็นแถวเดียวแบบต้นฉบับ**: ปุ่มจับ · ลำดับ · ประเภท · ช่องกรอก · ลบ
- **จัดลำดับได้จริง**: ลากทั้งแถวด้วยปุ่มจับ ⠿ หน้าแถว (เดิมมีแต่ข้อความบอก ไม่มีที่ให้ลาก) · คีย์บอร์ด: โฟกัสปุ่มจับแล้วกดลูกศรขึ้น/ลง (action `mv-qr` / `mv-bc` ใน `store.svelte.js`)

## ส่วนที่ต่างจากต้นฉบับ (ตั้งใจ)

หน้าตา (ตาม Design System):
1. ทุกชิ้นเป็น component ของ shadcn ตาม DS: การ์ด เมนูข้าง รายการ ป้าย ปุ่ม ช่องกรอก ตาราง หน้าต่าง
2. ประเภทเคสใช้สีเดิมของต้นฉบับ (พื้นแถว + แถบซ้าย 4px) · หน้าแถวเป็นรูปโปรไฟล์ลูกค้า
3. Merchant บนมือถือเปิดจากปุ่มเมนูบนแถบบน (แผงเลื่อน) แทนแท็บ "Merchant"
4. มีโหมดสว่าง/มืด สลับที่แถบบน ต้นฉบับมีแค่โหมดมืด
5. ไอคอนอีโมจิ/สัญลักษณ์ของต้นฉบับเปลี่ยนเป็น lucide ทั้งหมด · เมนู burger มีไอคอนแทนจุดสี
6. toast ปิดเคสเขียน "ปิดเคสแล้ว" (เดิม "…การ์ดเปลี่ยนเป็นสีขาว" ซึ่งไม่จริงแล้ว)

แก้บั๊กของต้นฉบับ (ทำให้ข้อมูลหายหรือเลย์เอาต์พัง):
7. กล่อง "ผู้โอน" ในผลตรวจสลิปหายบนจอแคบ (คลาส `col` ชนกัน)
8. กลับจากหน้า Announce/Settings บนมือถือ คอนโซลกลายเป็น grid 3 คอลัมน์
9. แผงขวาไม่อัปเดตหลังปิดเคส (ต้นฉบับวาดทั้งก้อนใหม่เฉพาะบางส่วน) · ตัวอย่างคีย์ลัดอัปเดตทันทีขณะพิมพ์
10. ฟองแชทหักข้อความสั้นกลางคำ ("ถอน200" → "ถอน2 / 00")

การเข้าถึง:
11. ห้องแชทเป็น `role="log"` โปรแกรมอ่านหน้าจออ่านข้อความใหม่ให้
12. โหมดลดการเคลื่อนไหวตัดเฉพาะการเลื่อน/ซูม/หมุน ตัวหมุน "AI ตรวจสลิป" ยังหมุนช้า ๆ
